# Juri Cooks

مخبز جوري التفاعلي: موقع وصفات عربي متجاوب بأجواء دافئة ورسومات CSS مصممة خصيصًا، مبني بملفات HTML وCSS وJavaScript مستقلة دون اعتماد على إطار عمل.

## التشغيل

افتحي `index.html` في المتصفح. يمكن نشر المجلد كما هو على GitHub Pages أو أي استضافة ملفات ثابتة.

## المزايا

- افتتاحية أبواب مخبز متحركة، توهج فرن، واجهة عرض مرسومة بـ CSS، وبخار وفتات ضوء متحركة.
- ظهور تدريجي مع التمرير، حركة خفيفة للمشهد مع مؤشر الفأرة، ومؤشر تقدم للقراءة.
- صينية تجهيز تحفظ وصفاتك والمقادير التي علّمتِ عليها.
- سجل مخبوزاتي: ختم لكل مرة تخبزين فيها الوصفة مع احتفال نجوم.
- مؤقّت فرن مع تنبيه صوتي، واختيار وصفة اليوم بحركة سحب مخبز.

- تصنيفات، بحث، مفضّلة، وتصفّح وصفة عشوائية.
- صفحتا وصفة للسينامون رول وخبز الساندويتش السريع على المقلاة.
- وضع طبخ خطوة بخطوة، تقييم، وملاحظات شخصية.
- إضافة وصفات جديدة وحفظ البيانات محليًا في المتصفح عبر `localStorage`.
- تصميم عربي RTL متجاوب مع حركات خفيفة ورسومات زخرفية CSS، بلا صور فوتوغرافية.
