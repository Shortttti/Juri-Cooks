# Juri Cooks

دفتر وصفات شخصي عربي بتصميم متجاوب، مبني بملفات HTML وCSS وJavaScript مستقلة دون اعتماد على إطار عمل.

## التشغيل

افتحي `index.html` في المتصفح. يمكن نشر المجلد كما هو على GitHub Pages أو أي استضافة ملفات ثابتة.

## المزايا

- تصنيفات، بحث، مفضّلة، وتصفّح وصفة عشوائية.
- صفحتا وصفة للسينامون رول وخبز الساندويتش السريع على المقلاة.
- وضع طبخ خطوة بخطوة، تقييم، وملاحظات شخصية.
- إضافة وصفات جديدة وحفظ البيانات محليًا في المتصفح عبر `localStorage`.
- تصميم عربي RTL متجاوب مع حركات خفيفة ورسومات زخرفية CSS، بلا صور فوتوغرافية.
